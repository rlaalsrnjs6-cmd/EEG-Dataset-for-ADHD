SaMD(Software as a Medical Device)

독립형 의료기기 소프트웨어
하드웨어 없이 소프트웨어 자체가 의료기기인 경우
예시) 진단, 치료, 예후 예측, 모니터링, 질병 검출

단 소프트웨어가 의료적인 판단(진단, 치료, 모니터링 등)에 직접 사용되야지 SaMD일 가능성이 높다 단순 병원 예약 앱은 SaMD가 아니다.

SaMD에서 가장 많이 사용하는 국제표준
SaMD
 │
 ├── ISO 13485
 │      │
 │      QMS
 │
 ├── IEC 62304
 │      │
 │      Software 개발
 │
 ├── ISO 14971
 │      │
 │      위험관리
 │
 └── IEC 62366
        │
        사용성(Usability)

ISO13485

의료기기 품질경영시스템(QMS,Quality Management System)에 대한 *"국제표준"

- 목적
1) 환자의 안전 확보
2) 의료기기의 품질 유지
3) 법규 준수
4) 지속적인 품질개선

- 적용대상
1) 의료기기 제조사
2) 의료기기 개발사
3) AI 의료기기 개발사
4) 체외진단기기
5) 의료기기 부품업체
6) 소프트웨어 의료기기(SaMD)

- 구조
1) 적용범위
2) 참고규격
3) 용어 및 정의
4) *품질경영시스템(QMS)
5) *경영책임
6) *자원관리
7) *제품실현
8) *측정,분석,개선

- 4장.품질경영시스템(QMS)
 품질경영시스템은 제품이나 서비스를 일정한 품질로 개발,생산,관리하기 위한 조직의 모든 절차와 규칙을 체계화한 시스템
대표적으로
  품질매뉴얼
 ├ SOP
 │   ├ 설계관리
 │   ├ 문서관리
 │   ├ 변경관리
 │   ├ CAPA
 │   ├ 내부심사
 │   ├ 교육관리
 │   └ 구매관리
 ├ 작업지침서
 └ 기록

- 5장.경영책임
 경영자가 해야하는일
예시
1) 품질방침 수립
2) 품질목표 설정
3) 품질책임자 지정
4) 경영검토 실시

- 6장.자원관리
 좋은 제품을 만들기 위해 필요한 자원을 관리
예시
1) 인력
2) 교육
3) 시설
4) 장비
5) 개발환경
6) 소프트웨어

- 7장.제품실현
 의료기기를 실제 개발하는 과정입니다.
포함되는 내용
1) 요구사항
2) 설계
3) 개발
4) 구매
5) 생산
6) 시험
7) 검증
8) 출하

- 설계관리
대표적으로
1) SRS(Software Requirements Specification) : 소프트웨어 요구사항 정의 ex)요구사항 명세서
2) SDP(Software Development Plan) : 개발 계획 수립 ex)개발 계획서
3) SDS(Software Design Specification) : 소프트웨어 설계 : 설계서
4) Architecture : 시스템 구조 설계 ex)아키텍쳐 문서
5) V&V Plan(Verification & Validation Plan) : 검증 및 유효성확인 계획 ex)시험 계획서
6) Risk Analysis : 위험분석 ex)위험관리 문서
7) Traceability Matrix : 요구사항 추적 ex) 추적성 매트릭스

- 변경관리
 변경사항이 적용되면 영향분석 -> 승인 -> 테스트 -> 릴리즈 절차를 수행해야함

- 문서관리
 문서의 최신버전 관리

- 형상관리
대표적으로 
1) Git
2) Github
3) GitLab
관리대상
1) 코드
2) 문서
3) 모델
4) 데이터셋
5) 테스트 결과

- 검증 및 확인(V&V)
 Verification : 제대로 만들었는가
예시
1) 코드 리뷰
2) 단위시험
3) 통합시험
Validation : 사용 목적에 맞는가?
예시
ADHD AI프로그램 제작시 실제 EEG 데이터를 이용하여 정확도가 요구사항을 만족하는지 평가

- 위험관리(따로 파일있음)
ISO 14971과 함께 사용
위험을
1) 분석
2) 평가
3) 감소
하는 것이 Risk Management

- CAPA(따로 파일있음)
 Corrective And Preventive Action
불량 발생시
문제 발생 -> 원인 분석 -> 수정 -> 재발방지 -> 효과확인 수행

- 내부심사
 회사 내부에서 자체적인 감사를 시행 보통 1년에 1회 이상 실시

- 제8장 개선
 대표적으로
1) 고객불만
2) NC(부적합)
3) CAPA
4) 내부심사
5) 데이터분석
6) 지속적 개선

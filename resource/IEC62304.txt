IEC62304
소프트웨어 개발 프로세스
요구사항, 설계, 구현, 테스트, 유지보수 등 포함

위험도 구분
A : 환자에게 피해 X
B : 오류 발생 경미한 위해
C : 오류 발생 중대한 위해 또는 사망

클래스가 높을수록 문서, 테스트, 리뷰 증가

진행과정
SDP(Software Development Process)
계획(SDP)->요구사항(SRS)->설계(SDD)->구현(코드작성)->단위시험(함수,메서드하나 검사)->통합시험(모듈간 인터페이스 확인)->시스템시험(전체 테스트)->릴리즈

SDP(Software Development Plan)
어떻게 개발할건지?
계획

Software Requirement Specification(SRS)
무엇을 만들것인가?
정의

Software Design Description(SDD)
어떻게 만들것인가?
설계

V&V(Verification&Validation)
Verification 제대로 만들었는가?
Validation 사용자의 니즈에 적합한가?

형상관리(Configureation Management)
예시 : git
관리대상
소스코드,문서,시험결과,버전 등

유지관리
출시 후 사후관리

문제해결
버그발생->CAPA->변경관리->재시험->릴리즈

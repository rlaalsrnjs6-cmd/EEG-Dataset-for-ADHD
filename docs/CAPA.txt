CAPA(Corrective and Preventive Action)
문제의 근본 원인을 제거하고(Corrective Action), 재발을 예방하는(Preventive Action) 품질 개선 프로세스

진행과정
문제발생->NC등록->원인조사(Root Cause Analysis)->시정조치(Corrective Action)->예방조치(Preventive Action)->효과확인(Effectiveness Check)->CAPA종료

문제발생
버그발생

NC(Nonconformity)등록
문제 상세내용 작성

원인분석
- 5 Why : 5회 왜?를 반복하여 질문하며 근본 원인을 찾는다
- Fishbone Diagram(어골도, Ishikawa Diagram) : 생선뼈 처럼 원인을 카테고리 별로 나누어 분석
- Fault Tree Analysis(FTA) : 결과에서 시작해서 원인을 트리 형태로 논리적으로 추적하는 방법, AND OR 논리를 사용
- 8D(Eight Disciplines) : 8D는 원인 분석뿐 아니라 문제 해결 전체 절차
1) D1 : 팀 구성
2) D2 : 문제 정의
3) D3 : 임시 조치
4) D4 : 근본 원인 분석
5) D5 : 시정조치 결정
6) D6 : 시정조치 실행 및 검증
7) D7 : 재발 방지
8) D8 : 팀 인정 및 종료
등이 있다.

시정조치(Corrective Action)
현재 발생한 문제를 해결

예방조치(Preventive Action)
추후 재발을 예방합니다.

효과 확인
확인후 효과 입증시 CAPA 종료 가능.
